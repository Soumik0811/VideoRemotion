# Shared animation core

Reusable, episode-independent Remotion systems belong here as they are extracted from existing episode implementations. Before moving a component, update all imports and the matching `studio/library.json` entry in the same change. The current shared curious-style primitives and cutout character remain in `src/curious/` so the existing UnitEconomics03 composition continues to resolve.

Do not copy episode-specific storyboards, narration, audio, or financial assumptions into this folder.
